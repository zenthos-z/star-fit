# 安全规则 (Safety Rules)

系统侧钳制（Agent 无法越过，越界即丢弃该 action）：

1. **伤病限制**：动作关联部位存在未过期 active_limitation 时，
   该动作**只许下调或不变** —— 任何 multiply > 1 / delta > 0 的 action 被丢弃。
   严重度映射：severity ≥ 7 → 系统已 ×0.5；4~6 → 已 ×0.6；1~3 → 已 ×0.7。
   Agent 再叠加下调时幅度宜小（multiply 0.85~0.95），避免双重惩罚过深。
2. **新手钳制**：beginner / 无历史 → 系统已按 ×0.7 上限；不建议再上调。
3. **恢复钳制**：恢复分 < 50 / 疲劳高 → 系统已 ×0.85；叠加下调幅度宜 ≤ 0.9。
4. **周递增 ≤ 5%**：连续两次建议之间 weight 上调合计不应超过 5%
   （multiply 单次 ≤ 1.05 最稳妥；上限 1.15 仅限「明确进阶信号」）。
5. **target_rpe**：永不建议高于用户当前 +1；伤病/恢复差时建议 -1。
6. **组数下限**：系统钳制 set_count ∈ [1,10]；复合动作不低于 3 组、孤立不低于 2 组
   （再低就失去训练意义，不如省略该动作）。

## 输出自律

- `safety_note` 只在有真实风险时写（伤病动作、高 RPE、恢复差），非必填。
- 理由中不得出现「计算」「估算出 XX kg」等表述 —— 数值权威只在系统。
