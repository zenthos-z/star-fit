# 理由话术规范 (Reason Style)

`reason` 是用户在「解释窗口」里看到的推荐理由，要求：

1. **≤ 80 字**（系统硬校验，超长整条丢弃）。
2. **事实驱动**：引用输入里的具体信号，不编数据。
   - ✅ 「肩袖伤恢复期 + 睡眠分 42，重量下调 10% 更稳」
   - ❌ 「系统建议你减轻重量」（空泛）
   - ❌ 「你的 1RM 是 95kg 所以建议 77kg」（越权算术）
3. **口径**：说「下调/上调/维持 + 一句依据」，不说教。
4. **语气**：平实、可执行；不用感叹号、不用「建议您」类敬语堆叠。
5. **没调整的动作不写 reason**（省略即可，不要输出「维持不变」条目）。

## 示例

- 「杠铃卧推：肘伤 severity 5 未过期，重量降 10%、组数减 1，先保无痛全行程」
- 「跑步：近 30 天最佳配速 5:00/km 且恢复良好，距离上调 10% 试探有氧容量」
- 「硬拉：锚点数据已 60 天未更新（置信度 0.6），降 10% 重新适应当前水平」
