# 分化方案选择决策表 (Split Selection)

> Agent 为用户编排"每周 X 练"计划时的分化决策依据。
> 分化只由两个变量决定：**每周可用天数**（画像 preferences）与**经验等级**（fitness_level）。
> 永远不要给用户安排超出其可用天数的分化。

## 一、按每周天数选分化

| 每周天数              | 推荐分化                   | 适用等级   | 说明                                                     |
| --------------------- | -------------------------- | ---------- | -------------------------------------------------------- |
| 2-3 天                | 全身分化（Full Body）      | 初学者首选 | 每次覆盖全肌群，动作模式学习效率最高；频率与恢复天然平衡 |
| 4 天                  | 上下分化（Upper/Lower ×2） | 初学到中级 | 每肌群一周 2 次刺激，容量与频率兼得                      |
| 5 天                  | 上下 + 推拉腿混合          | 中级       | 通常 Upper/Lower/Upper/Push/Pull 或类似编排              |
| 6 天                  | 推拉腿 ×2（PPL）           | 中高级     | 容量大，要求恢复到位；初学者禁止                         |
| 5-6 天 + 想练多于恢复 | 推拉腿 + 弱项日            | 高级       | 第 6 天留给最薄弱肌群                                    |

## 二、编排校验清单

生成周计划后，Agent 按以下规则自查（不满足则调整编排）：

1. **推拉平衡**：一周内"推类动作组数 ≈ 拉类动作组数"（±20%）。全推不拉是伤病温床。
2. **同城肌群间隔**：同一肌群酸痛未消（一般 48-72 小时）不连续两天安排大容量训练。
   例：周一硬拉大容量 → 周二不排大容量弯腰类/腘绳肌动作。
3. **复合动作前置**：每个训练日内，复合动作排在孤立动作之前。
4. **腿部优先占座**：腿部日在周内的位置不要总被用户"顺手跳过"，避免总排在最忙的一天。

## 三、时间受限时的压缩规则

用户当天时间不足（如 30 分钟）时的降级顺序：

1. 砍孤立动作，保留复合动作
2. 保留原计划的 2 个主复合动作，各做 2-3 组
3. 次数范围上调一档、重量下调 10-20%，缩短组间休息
4. 实在不行改为"当日最低剂量"：1 个复合动作 3 组 + 记录"维持模式"

**关键**：降级后的训练仍算完成。绝不用"练不满 45 分钟不如不练"的叙事。

## 四、器械受限映射

与画像 preferences.equipment 的硬约束联动：

| 可用器械 | 分化调整                                                                      |
| -------- | ----------------------------------------------------------------------------- |
| 仅哑铃   | 全身或上下分化不变；推类用哑铃卧推/肩推替代杠铃，增加单侧动作平衡弱侧         |
| 自重为主 | 次数上调（12-20+）、组间休息缩短、加入递减组；用节奏变化（离心 3-4 秒）补强度 |
| 全健身房 | 按标准决策表执行                                                              |

## 来源

提炼自 workout-planner（JayRHa/AgentSkills, MIT）的 splits 决策框架，
按本产品"用户画像最高宪法"约束改写：分化选择必须能通过计划卡校验（动作/容量不突破画像），
突破画像器械约束的计划会被拒绝。
