# 新手起步（重量推算与起步分支）

> 自 plan-generation/knowledge.md §3 拆分（42c）。SKILL.md 与 BASE prompt 中
> 「PRE 重量规则 / knowledge.md §3.2.0 单一真源」指向本文件。

## 一、有历史记录的情况（§3.1）

当用户有历史负荷锚点时：

1. **使用历史 1RM**：训练重量 = 历史 1RM × 80%
2. **使用历史最佳重量**：训练重量 = 历史重量 × 85-95%
3. **递增规则**：每周增加 2-5%

## 二、推算前置检查（§3.2.0 数据依赖链门禁）

重量推算依赖链：抗阻/自重/助力动作的重量都锚定在用户体重上。
出计划前必须核对 load_history 返回的 profile_static / profile_dynamic：

| 依赖数据              | 下游用途                                           | 缺失时动作                                                                                                                                                                                                                                  |
| --------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| basic_info.weight     | 抗阻推算 / assisted 辅助定位 / bodyweight 有效负荷 | **必问**（survey_card 数字题，注明用途）                                                                                                                                                                                                    |
| basic_info.age        | 有氧心率区间（%HRmax，HRmax≈208−0.7×age）          | 计划含 cardio/outdoor 心率目标时必问                                                                                                                                                                                                        |
| preferences.equipment | 动作过滤                                           | **必问**（多选）                                                                                                                                                                                                                            |
| goal / method         | 容量与动作选择                                     | **必问**                                                                                                                                                                                                                                    |
| load_anchors（抗阻）  | 训练重量                                           | 走系统提示的 PRE-test 规则——**按经验分支**：beginner/自选 → 直接给空杆(20kg)或最小配重(2.5-5kg)起步并在备注标「第一次找感觉」，练完报实际重量存为锚点；intermediate/advanced 或用户主动选自测 → 出 PRE instruction 引导自测后按报的重量出卡 |
| fitness_level         | 容量定位                                           | 可假设 beginner 并在正文声明                                                                                                                                                                                                                |

规则：

1. 缺「必问」数据 → 本轮只发 survey_card 收集，**不出 plan_card**（与 PRE-test
   规则同构：先补数据，再出计划）。多题合并为一张卡，一次问完。
2. bodyweight 动作 weight=0 是正确值，不需要为此询问；询问体重是为了
   assisted 辅助定位与抗阻推算，问卷文案要说清用途（用户才知道为什么问）。
3. 用户拒绝回答 → 按规则 4 的起步重量（空杆/最小配重）出计划并在正文说明
   「先找感觉，练完报实际重量」（2026-09-23 起 weight=0 会被校验器打回，
   只有 bodyweight 动作允许 0）。
4. **新手起步重量分支（2026-09-23 拍板）**：experience=beginner 或用户选
   「自己试/不知道怎么测」时，禁止要求用户先报出所有动作重量——直接出
   plan_card：杠铃复合动作给空杆 20kg（或器械最小配重片），哑铃/绳索/器械
   单关节给最小可用增量（2.5-5kg），每个此类动作的 note 写「第一次找感觉：
   动作标准优先，练完把实际重量告诉我，下次按它进阶」。练后用户报实际
   重量 → update_profile 存 load_anchors。新手不缺「测出来的重量」，缺的
   是「开始的最低门槛」。
5. **历史记录导入钩子**：用户 load_anchors 为空且像有训练经验时，主动提示
   可以发旧训练记录截图（App 图片按钮），Agent 读取图中动作+重量+次数 →
   profile_update_confirm 确认 → update_profile 写入 load_anchors。

## 三、推算公式（§3.2.1，前置检查通过后）

根据动作类型和用户体重推算：

| 动作类型 | 推算公式         | 说明             |
| -------- | ---------------- | ---------------- |
| 深蹲     | 体重 × (0.4-0.6) | 初学者取下限     |
| 卧推     | 体重 × (0.4-0.6) | 女性取下限       |
| 硬拉     | 体重 × (0.5-0.7) | 需要更强的基础   |
| 上肢孤立 | 体重 × 0.1-0.2   | 弯举、侧平举等   |
| 下肢孤立 | 体重 × 0.2-0.3   | 腿屈伸、腿弯举   |
| 自重动作 | 0 kg             | 俯卧撑、引体向上 |
| 器械动作 | 哑铃 × 0.7-0.8   | 通常比自由重量轻 |

## 四、特殊情况（§3.3，伤病恢复期见 injury-adjustment.md）

- **首次训练**：使用推算重量的 70% 作为试探
- **器械不熟悉**：降低 20% 以确保安全
- **体重未知且用户拒绝提供**：禁止使用任何虚构体重做推算；抗阻动作全部走
  PRE-test 自选重量，assisted 动作以「能标准完成 8-10 次」为辅助量试做标准
