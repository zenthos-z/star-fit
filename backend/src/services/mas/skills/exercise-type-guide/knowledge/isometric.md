# isometric - 等长收缩详细知识

## 一、定义与科学原理

### 定义
肌肉在发力过程中长度不变，关节角度保持固定的静态收缩训练。

### 生理机制
- **肌纤维募集**：激活所有运动单位，包括高阈值单位
- **时间-张力积分**：静态维持时间越长，训练刺激越大
- **神经适应**：提高运动单位募集效率

## 二、应用场景
- 核心稳定性训练
- 关节稳固训练
- 康复期静态维持
- 力量平台突破

## 三、参数设置规范

### 必需字段
- **duration**: 维持时间（秒），必须 > 0

### 可选字段
- **weight**: 负重等长（如负重平板支撑）

### 字段约束
| 字段 | 类型 | 最小值 | 最大值 | 默认值 | 说明 |
|------|------|--------|--------|--------|------|
| duration | number | 10 | 600 | 30 | 单位：秒 |
| weight | number | 0 | - | 0 | 可选负重 |
| sets | number | 1 | 10 | 3 | 根据耐力目标 |
| reps | number | 1 | 1 | 1 | 通常固定为 1 |

## 五、训练建议

| 水平 | 时长 | 组数 | 组间休息 |
|------|------|------|---------|
| 初学者 | 10-30 秒 | 2-3 组 | 60 秒 |
| 中级者 | 30-60 秒 | 3-4 组 | 90 秒 |
| 高级者 | 60-120 秒 | 4-5 组 | 120 秒 |

## 六、常见动作举例

- **平板支撑**: 3组 x 1次 x 30秒
- **靠墙半蹲**: 3组 x 1次 x 45秒
- **侧支撑**: 3组 x 1次 x 30秒/侧
- **L-坐**: 3组 x 1次 x 20秒

## 七、注意事项

**常见错误**
1. 缺少 duration 字段 → 验证失败
2. duration 设置过短 → 训练效果不足
3. reps 设置不为 1 → 不符合等长收缩特点

**正确做法**
1. 保持呼吸顺畅，不要憋气
2. 注意身体对齐，避免代偿
3. 血压患者慎用长时间维持
4. 优先保证动作质量而非时长
