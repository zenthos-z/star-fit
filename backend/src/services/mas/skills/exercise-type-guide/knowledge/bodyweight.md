# bodyweight - 自重训练详细知识

## 一、定义与科学原理

### 定义
利用自身体重作为阻力的训练方式，无需额外器械。

### 适用场景
- 器械受限环境（居家、出差）
- 徒手训练爱好者
- 康复期过渡训练
- 功能性动作模式训练

## 二、训练目标与参数

| 训练目标 | 难度调整方式 | 组数 | 次数 |
|---------|-------------|------|------|
| 基础力量 | 标准动作 | 2-3 组 | 8-15 次 |
| 肌耐力 | 增加次数/减少休息 | 3-5 组 | 15-30 次 |
| 爆发力 | 快速爆发 | 3-5 组 | 5-10 次 |

## 三、参数设置规范

### 必需字段
- 无

### 可选字段
- **weight**: 通常设为 0，特殊情况可使用负重板

### 字段约束
| 字段 | 类型 | 最小值 | 最大值 | 默认值 | 说明 |
|------|------|--------|--------|--------|------|
| weight | number | 0 | 0 | 0 | 通常为 0 |
| sets | number | 1 | 20 | 3 | 根据难度调整 |
| reps | number | 1 | 200 | 15 | 根据难度调整 |

## 四、标准 JSON 格式

```json
{
  "id": "V1StGXR8_Z5jdHi6",
  "name": "俯卧撑",
  "exercise_type": "bodyweight",
  "sets": 3,
  "reps": 15,
  "weight": 0
}
```

## 五、常见动作举例

- **俯卧撑**: 3组 x 15次 x 0kg
- **深蹲**: 3组 x 20次 x 0kg
- **引体向上**: 3组 x 8次 x 0kg
- **平板支撑**: 3组 x 30秒 x 0kg
- **波比跳**: 3组 x 10次 x 0kg

## 六、难度进阶

### 俯卧撑进阶
1. 跪姿俯卧撑 → 2. 标准俯卧撑 → 3. 钻石俯卧撑 → 4. 负重俯卧撑

### 深蹲进阶
1. 浅蹲 → 2. 标准深蹲 → 3. 单腿深蹲 → 4. 跳跃深蹲

## 七、注意事项

**常见错误**
1. 忽略 weight 字段 → 应设置为 0
2. 动作质量差 → 宁缺毋滥，先保证质量

**正确做法**
1. 根据用户水平选择合适难度
2. 强调动作标准性而非数量
3. 可与 resistance 动作结合使用
