# unilateral - 单侧训练详细知识

## 一、定义与科学原理

### 定义
一次训练单侧肢体的动作，两侧交替或分别进行。

### 优势
- 纠正左右不平衡
- 提高核心稳定性
- 模拟真实运动模式
- 减少脊柱负荷

## 二、参数设置规范

### 必需字段
- **weight**: 重量（kg），必须 >= 0

### 可选字段
- 无

### 字段约束
| 字段 | 类型 | 最小值 | 最大值 | 默认值 | 说明 |
|------|------|--------|--------|--------|------|
| weight | number | 0 | - | 根据用户 | 可为0 |
| sets | number | 1 | 20 | 3 | 每侧组数 |
| reps | number | 1 | 100 | 12 | 每侧次数 |

## 四、常见动作举例

### 下肢
- **箭步蹲**: 3组 x 12次/侧 x 15kg
- **保加利亚分腿蹲**: 3组 x 10次/侧 x 10kg
- **单腿硬拉**: 3组 x 8次/侧 x 20kg

### 上肢
- **单臂划船**: 3组 x 12次/侧 x 15kg
- **单臂卧推**: 3组 x 10次/侧 x 20kg
- **侧平举**: 3组 x 15次/侧 x 5kg

## 五、训练建议

### 组数说明
- sets 表示每侧的组数
- 实际训练量为 sets × 2（左右各做）

### 进阶方式
1. 增加重量
2. 增加次数
3. 减少支撑稳定性（如单腿站立）

## 六、注意事项

**常见错误**
1. weight 设置为负值 → 应 >= 0
2. 左右重量不一致 → 保持一致

**正确做法**
1. 先练弱侧，后练强侧
2. 以弱侧为准控制训练量
3. 注意核心稳定，避免代偿
