# assisted - 辅助训练详细知识

## 一、定义与科学原理

### 定义

借助器械辅助完成动作，通过抵消部分体重或提供助力。

### 应用场景

- 力量不足无法完成标准动作
- 动作学习阶段
- 逐渐减少辅助实现进阶

## 二、参数设置规范

### 必需字段

- **weight**: 辅助重量（kg），必须 > 0

### 可选字段

- 无

### 字段约束

| 字段   | 类型   | 最小值 | 最大值 | 默认值   | 说明         |
| ------ | ------ | ------ | ------ | -------- | ------------ |
| weight | number | 1      | -      | 根据用户 | 可为负值     |
| sets   | number | 1      | 20     | 3        | 根据目标调整 |
| reps   | number | 1      | 50     | 10       | 根据目标调整 |

## 三、标准 JSON 格式


## 四、常见动作举例

### 引体向上辅助

- **助力引体**: 3组 x 10次 x -30kg（辅助30kg）
- **弹力带辅助**: 3组 x 8次 x -15kg

### 俯卧撑辅助

- **上斜俯卧撑**: 3组 x 12次 x 0kg
- **器械辅助俯卧撑**: 3组 x 15次 x -20kg

### 臂屈伸辅助

- **助力臂屈伸**: 3组 x 12次 x -25kg

## 五、进阶方案

辅助重量与体重的比例关系（2026-09-18 补）：下表按 ~60-70kg 体重用户标定。
实际辅助量 ≈ 体重 × 比例（初级 40-55%、中级 25-40%、高级 15-25%）。
用户体重大幅偏离 65kg 时按比例修正；体重数据缺失时先走
plan-generation 知识 §3.2.0 的依赖链门禁询问体重，不要凭空给绝对值。

| 阶段 | 辅助重量      | 比例（×体重） | 目标           |
| ---- | ------------- | ------------- | -------------- |
| 初级 | -40kg ~ -30kg | 50-60%        | 学习动作模式   |
| 中级 | -25kg ~ -15kg | 30-40%        | 建立基础力量   |
| 高级 | -10kg ~ -5kg  | 15-25%        | 过渡到标准动作 |
| 完成 | 0kg           | 0%            | 标准动作       |

## 六、注意事项

**常见错误**

1. weight 为正值 → 应使用负值表示辅助
2. 直接跳到无辅助 → 应渐进减少辅助

**正确做法**

1. 使用负值表示辅助重量（如 -20kg）
2. 每次减少 5-10kg 辅助
3. 先保证动作质量再减少辅助
4. 达到 -5kg 可尝试标准动作
