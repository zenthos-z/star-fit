# flexibility - 柔韧性训练详细知识

## 一、定义与科学原理

### 定义
提高关节活动度和肌肉伸展性的训练。

### 生理机制
- **肌肉延展性**：提高肌纤维和结缔组织弹性
- **关节活动度**：改善关节囊和韧带灵活性
- **神经放松**：降低肌张力，减少肌肉紧张

## 二、训练类型

### 静态拉伸 (Static Stretching)
- 保持拉伸位置 15-60 秒
- 适合训练后放松
- 不建议训练前长时间静态拉伸

### 动态拉伸 (Dynamic Stretching)
- 主动运动，逐渐增加幅度
- 适合训练前热身
- 提高体温和血流量

### PNF 拉伸
- 收缩-放松技术
- 需要辅助或器械
- 效果最佳但操作复杂

## 三、参数设置规范

### 必需字段
- 无

### 可选字段
- **duration**: 每次拉伸时长（秒）

### 字段约束
| 字段 | 类型 | 最小值 | 最大值 | 默认值 | 说明 |
|------|------|--------|--------|--------|------|
| duration | number | 15 | 60 | 30 | 单位：秒 |
| sets | number | 1 | 5 | 2 | 拉伸组数 |
| reps | number | 1 | 1 | 1 | 通常固定为 1 |
| weight | number | 0 | 0 | 0 | 不适用 |

## 五、常见动作举例

### 下肢拉伸
- **股四头肌拉伸**: 2组 x 1次 x 30秒/侧
- **腘绳肌拉伸**: 2组 x 1次 x 30秒/侧
- **小腿拉伸**: 2组 x 1次 x 30秒/侧

### 上肢拉伸
- **胸肌拉伸**: 2组 x 1次 x 30秒/侧
- **背阔肌拉伸**: 2组 x 1次 x 30秒/侧
- **肩部拉伸**: 2组 x 1次 x 30秒/侧

## 六、训练建议

### 训练时机
- **训练后**: 主要拉伸时机，效果最佳
- **休息日**: 独立拉伸训练
- **训练前**: 以动态拉伸为主，静态拉伸不超过10秒

### 持续时间
| 目的 | 推荐时长 |
|------|---------|
| 基础拉伸 | 15-30 秒 |
| 深度拉伸 | 30-60 秒 |
| PNF 拉伸 | 10 秒收缩 + 30 秒放松 |

## 七、注意事项

**常见错误**
1. 拉伸时疼痛 → 应有牵拉感但无痛感
2. 训练前长时间静态拉伸 → 可能降低运动表现

**正确做法**
1. 动作缓慢，避免弹震
2. 保持正常呼吸，不要憋气
3. 感觉牵拉感即可，不要追求疼痛
4. 受伤后恢复期遵医嘱
