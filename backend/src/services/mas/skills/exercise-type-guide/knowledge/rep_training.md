# rep_training - 次数训练详细知识

## 一、定义与科学原理

### 定义
以完成次数为核心目标，而非重量的训练方式。

### 应用场景
- 徒手动作次数挑战
- 动作模式熟练
- 肌耐力突破
- 记录个人最佳次数

## 二、参数设置规范

### 必需字段
- 无

### 可选字段
- **weight**: 重量（kg），通常为 0

### 字段约束
| 字段 | 类型 | 最小值 | 最大值 | 默认值 | 说明 |
|------|------|--------|--------|--------|------|
| weight | number | 0 | 0 | 0 | 通常为 0 |
| sets | number | 1 | 10 | 1 | 次数挑战通常 1 组 |
| reps | number | 1 | 500 | 目标次数 | 核心目标 |

## 六、训练方案

### 金字塔训练
1. 第1组：50% 最大次数
2. 第2组：75% 最大次数
3. 第3组：100% 最大次数（尽全力）

### 累计次数训练
- 不限组数，累计达到目标总次数
- 例如：100个俯卧撑，最少组数完成

### 间歇次数训练
- 固定组数，组间休息 60-90 秒
- 每组尽可能多做，记录总次数

## 七、进阶策略

### 增加次数
1. 每次训练增加 1-2 次
2. 达到目标后，减少组间休息时间
3. 使用进阶动作变式

### 动作进阶（以俯卧撑为例）
1. 跪姿俯卧撑
2. 标准俯卧撑
3. 钻石俯卧撑
4. 负重俯卧撑

## 八、注意事项

**常见错误**
1. 次数设置过高 → 导致动作变形
2. 忽略动作质量 → 宁缺毋滥
3. sets 设置为 3-5 组 → 次数挑战通常 1 组

**正确做法**
1. 优先保证动作标准性
2. 量力而行设置目标次数
3. 记录每次成绩，追踪进步
4. 每周测试 1-2 次，避免过度训练
5. 可与 bodyweight 类型混用
