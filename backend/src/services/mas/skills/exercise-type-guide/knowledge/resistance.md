# resistance - 抗阻力训练详细知识

## 一、定义与科学原理

### 定义
抗阻力训练（Resistance Training），又称力量训练，是指肌肉对抗外部阻力（如哑铃、杠铃、器械等）进行的训练方式。

### 生理机制
- **肌肉肥大原理**：机械张力和代谢压力激活 mTOR 信号通路
- **神经适应**：运动单位募集模式和发放频率优化
- **骨密度提升**：Wolff 定律，机械刺激促进骨沉积

### 科学依据
- ACSM Position Stand: Progression Models in Resistance Training (2023)
- NSCA Essentials of Strength Training and Conditioning (2nd Ed.)

## 二、训练目标与参数对应

| 训练目标 | 强度 (%1RM) | 次数范围 | 组数 | 组间休息 |
|---------|-------------|---------|------|---------|
| 最大力量 (Strength) | 85-100% | 1-6 次 | 3-5 组 | 2-5 分钟 |
| 爆发力 (Power) | 30-60% | 1-6 次 | 3-6 组 | 2-5 分钟 |
| 肌肥大 (Hypertrophy) | 70-85% | 6-12 次 | 3-4 组 | 1-2 分钟 |
| 肌耐力 (Endurance) | 50-70% | 12-20+ 次 | 2-3 组 | 30-60 秒 |

## 三、参数设置规范

### 必需字段
- **weight**: 外部重量（kg），必须 > 0
  - 初学者：从 50-60% 1RM 开始
  - 中级者：70-80% 1RM
  - 高级者：80-90% 1RM

### 可选字段
- 无

### 字段约束
| 字段 | 类型 | 最小值 | 最大值 | 默认值 | 说明 |
|------|------|--------|--------|--------|------|
| weight | number | 1 | - | 根据用户 | 必须字段 |
| sets | number | 1 | 20 | 3 | 根据目标调整 |
| reps | number | 1 | 200 | 10 | 根据目标调整 |

## 五、常见动作举例

1. **深蹲变式**
   - 杠铃深蹲: 3组 x 8-10次 x 60kg
   - 哑铃深蹲: 3组 x 10-12次 x 25kg/只
   - 腿举: 3组 x 12-15次 x 80kg

2. **卧推变式**
   - 杠铃卧推: 4组 x 6-8次 x 70kg
   - 哑铃卧推: 3组 x 10-12次 x 22.5kg/只
   - 器械推胸: 3组 x 12-15次 x 50kg

3. **硬拉变式**
   - 传统硬拉: 3组 x 5次 x 100kg
   - 六角杠硬拉: 3组 x 8次 x 80kg
   - 罗马尼亚硬拉: 3组 x 10-12次 x 60kg

## 六、注意事项

**常见错误**
1. 缺少 weight 字段 → 导致验证失败
2. weight 设置为 0 → 自重动作才应为 0
3. 未参考用户负荷锚点 → 可能重量过重或过轻

**正确做法**
1. 优先调用 load_history 获取用户负荷锚点
2. 根据 fitLevel（beginner/intermediate/advanced）调整起始重量
3. 使用 strength_calculator 计算深蹲/卧推/硬拉

## 七、与其他类型的关系

- **bodyweight**: 自重动作 weight=0，抗阻力需要 weight>0
- **unilateral**: 单侧动作是抗阻力的一种变式
- **heavy_weight**: 大重量是抗阻力的高强度版本
