# 训练容量地标 (Volume Landmarks)

## 概述

本技能提供每个肌群「每周直接组数」的科学参考区间，用于训练计划的容量决策。
数字来自两套独立体系，技能内同时保留并标注置信度：

1. **RP Volume Landmarks**（Israetel / Renaissance Periodization）——教练经验
   体系（非 RCT），数字来自 RP 官方 hypertrophy guide（数千学员实践）；
2. **同行评审剂量-反应证据**——Schoenfeld 2017 meta（J Sports Sci）与
   Pelland 2025 meta-回归（Sports Medicine），提供「组数越多增长越大但有
   递减收益」的方向性结论。

**定义（单位 = 每周有效组数，working sets/week）**

| 地标 | 含义                                               |
| ---- | -------------------------------------------------- |
| MV   | 维持容量——保住现有肌肉所需最小量                   |
| MEV  | 最小有效容量——能产生增长的起点                     |
| MAV  | 最大适应容量——最佳增长区间（MEV~MRV 之间的递进带） |
| MRV  | 最大可恢复容量——超过则恢复失败、增长停止           |

**有效组计数规则**（RP 口径）：一组算「有效组」需满足 30-85% 1RM、每组
5-30 次、RIR 0-4（RPE 6-10）。只计目标肌群为主动肌的直接组；复合动作的
间接刺激已被表内数字折算，不要重复计数。

RP 现行文章）。区间为经验估计，个体差异大，必须结合用户反馈调整。

**MRV 与频率相关**（以胸为例，RP 官方数字）：2 次/周 ≈ 20 组，3 次 ≈ 25，
4 次 ≈ 30，5-6 次 ≈ 35。分配到更多训练日可提高可恢复总容量。

**单次训练上限**：单肌群单次建议 ≤ 5-12 组（Session MAV），超过递减收益
明显。日常计划单肌群单次直接组数以 ≤ 10 组为软上限。

## 同行评审证据（方向性结论，非具体数字）

- **Schoenfeld 2017**（J Sports Sci 35(11):1073-82，PMID 27433992）：
  15 项研究 34 处理组的 meta-回归。每多 1 组/周 → 效应量 +0.023（≈+0.37%
  肌肥大）；每周 ≥10 组组显著优于 <5 组。**结论：剂量-反应为正向分级
  关系**。局限：观察性汇总、组数定义不统一、无法确定上限拐点。
- **Pelland 2025**（Sports Med 56:481-505，DOI 10.1007/s40279-025-02344-w）：
  67 项研究 2058 人的贝叶斯 meta-回归（迄今最完整）。要点：
  1. 容量对肌肥大与力量的边际斜率 >0 的后验概率 100%——**加量确实有效**；
  2. **两者都呈递减收益**，力量的递减明显更陡；
  3. 频率对肌肥大的效应与零兼容（**组数总量比频率更重要**）；频率对力量
     有稳定正效应；
  4. 「分数计数法」（indirect sets 按 0.5 计）证据拟合最好。
- **证据分级结论**：RP 数字表 = 专家经验（中置信，实用基线）；「更多组数
  → 更多增长、递减收益」= 强证据；任何具体拐点数字（如「20 组是上限」）
  = 低置信，只能当起点。

## 应用规则（Agent 使用本表的方式）

1. **起点取 MEV~MAV 下沿**：新计划或新用户从中低容量起步，宁低勿高。
2. **递进而非一步到位**：4-6 周内每周加 1-3 组逼近 MRV，见平台期或恢复
   不良即回退（deload = 回到 MV 一周）。
3. **恢复信号降档**（按 workout_complete 反馈）：睡眠差/持续酸痛/表现
   下滑 → 本周容量降 20-30% 或回落 MV；recovery_state.fatigue_level 为
   high 及以上 → 只安排 MV 容量。
4. **人群修正**：新手 MEV 靠近 MV（增长容易，少量即涨）；训练 3 年以上
   MEV 上移 2-4 组；减脂期容量取区间下半段；伤病部位直接排除，不给折扣
   容量。
5. **不越界**：本表不覆盖力量举专项峰值周期（peaking），也不做医疗建议；
   用户有伤病时优先 active_limitations 过滤，容量表第二位。
