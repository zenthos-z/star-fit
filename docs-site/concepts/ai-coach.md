# AI 教练


AI 教练是系统的智能人格化接口，旨在提供有用、鼓舞人心且技术准确的指导。

## 提示词工程

教练的个性和知识在 `systemPrompts.ts` 中定义。关键原则：
- **角色**: 专业体能教练 (Strength & Conditioning Coach)。
- **语气**: 鼓舞人心但纪律严明。没有废话。
- **安全**: 始终优先考虑动作规范和伤害预防。

## RPE (主观疲劳度)

教练使用 RPE 来衡量强度，而不仅仅依赖重量数字。

| RPE | 描述 | 保留次数 (RIR) |
| :--- | :--- | :--- |
| 10 | 极限努力 | 0 |
| 9 | 非常困难 | 1 |
| 8 | 困难 | 2 |
| 7 | 中等 | 3 |

RPE 评估能力允许教练：
1.  在一组动作后询问用户的 RPE。
2.  将其与目标 RPE 进行比较。
3.  建议重量调整（例如，"RPE 是 6 但目标是 8，增加 5% 的重量"）。

## 上下文管理

教练的记忆分层：
- **短期**: 当前对话和活跃的训练会话。
- **长期**: 用户的健康水平、伤病和目标（存储在用户画像中）。

## 关于敏感建议

> 旧版本的 HITL（人机中断、`HitlConfirmCard` 暂停/批准/拒绝）机制已移除。敏感建议（如重量调整）改由**流式输出 + 用户自然确认**的方式呈现，不再使用 agent 级中断。
