# 运动卡片规范 (Exercise Card System)

运动卡片是训练执行过程中的核心交互单元。根据运动类型（力量、有氧、静力等），卡片采用不同的插件化渲染方案。

## 1. 容器与通用结构 (Container Structure)

运动卡片采用统一的卡片式容器，确保不同类型的运动在执行流中具有一致的视觉重量。

### 头部布局 (Header)
头部采用左右对齐的双栏结构，旨在快速传达运动核心身份：
- **左侧 (Identity)**: 
  - **装饰条**: `w-1.5 h-6` 的品牌色圆柱体 (Blue-500)，带微弱发光效果。所有卡片保持一致。
  - **运动名称**: `text-xl font-black` 的黑体文字。
- **右侧 (Tags)**: 
  - **类型标签**: 颜色依据运动类型映射，使用浅色背景与深色文字：
    - **力量**: `bg-blue-50 text-blue-500`
    - **有氧**: `bg-rose-50 text-rose-500`
    - **静力**: `bg-orange-50 text-orange-500`

## 2. 力量训练卡片 (Resistance Card) - [Blue Theme]

专为抗阻力训练设计，侧重于组数、重量和次数的管理。

### 头部 (Header)
- **运动名称**: 位于左侧，配有蓝色装饰条。
- **类型标签 (Badge)**: 位于右侧。
  - **统一规范**: 所有运动卡片的右上角标签统一采用 **蓝色 (Blue)** 风格。
  - **样式**: `bg-blue-50 text-blue-500`。
  - **文案**: 力量训练显示"力量"，静力动作显示"静力"，有氧运动显示对应的子模式（如"计时器"、"距离"）。

### 数据行 (Set Rows)
采用四列网格布局：`[组号] [重量] [次数] [完成按钮]`
1. **组号**: 两位数序号（如 `01`, `02`），必须从 1 开始显示。移除了顶部的"组"字以保持视觉极简。
2. **重量/次数**: 大字体数字 (`text-3xl font-black`)，下方配有单位标签 (`kg` / `次数`)。
3. **完成按钮**: 
   - **设计**: 位于右侧，方便大拇指快速点击。
   - **未完成**: 灰色圆圈图标。
   - **进行中 (休息)**: 橙色呼吸效果，显示剩余秒数。
   - **已完成**: 绿色勾选图标，背景变为绿色。
4. **简化设计**: 移除了操作按钮后的 RPE 标签，保持视觉轴线单一且纯粹。

## 3. 有氧训练卡片 (Running/Cardio Card) - [Rose Theme]

侧重于时长、距离和心率的实时监控。

### 头部 (Header)
- **左侧状态条**: 6px 宽垂直色块 (Blue-500)。
- **右侧标签**: `bg-rose-50 text-rose-500` 的有氧相关标签。

### 核心展示区 (Main Metric)
- **大字显示**: 实时跳动的时长或距离。
- **距离模式 (双列布局)**: 左侧显示目标公里（保留 1 位小数，如 `5.0 KM`），右侧显示实时计时，中间以细线分隔。
- **进度条**: 底部边缘嵌入式进度条（仅限倒计时模式）。
- **目标心率 (常驻)**: 在所有有氧模式（包括自由跑）下，在数据下方显示"目标心率区间 (Zone n)"。该标签在**运动中**与**已完成**状态下均保持显示，以防止布局抖动。

### 控制栏 (Control Bar)
底部不对称双按钮控制条，根据运动状态动态切换布局，强化极简视觉与操作逻辑：

- **初始状态 (Split Logic)**: 
  - 最初始状态下呈现为**完整的大按钮 (1col)**，仅包含"开始"。
  - 点击开始后，按钮产生**分裂效果**，过渡到不对称双栏布局 (grid-cols-[1fr_2.5fr])。
- **布局映射**:

| 状态 | 左侧按钮 (1fr) | 右侧按钮 (2.5fr) | 场景说明 |
| :--- | :--- | :--- | :--- |
| **准备中** | (无) | **开始 (全宽)** | 初始状态，极简单按钮 |
| **运动中** | **结束** | **暂停** | 右侧控制节奏，左侧允许提前终止 |
| **已暂停** | **完成** | **继续** | 运动中断，左侧确认保存，右侧恢复 |
| **已完成** | **撤销** | **已完成 (标签)** | 运动结束，左侧允许重回运动状态，右侧显示状态 |

- **设计逻辑**: 始终保持右侧按钮作为"主控制手柄"，比例 1:2.5，强化右手盲操。左侧按钮仅在有数据产生后激活，作为"状态终结"操作。
- **动效规范**: 布局切换需伴随 Framer Motion 的 `layout` 动画，使用 `spring` 物理引擎（stiffness: 300, damping: 25），实现有机的"分裂"感。左侧按钮进入时使用 `AnimatePresence` 配合 `initial=\{\{ opacity: 0, x: -20 \}\}` 实现平滑滑入。
- **颜色规范**:
  - **暂停 (Pause)**: 统一使用黄色系 (`bg-amber-500` 或 `text-amber-600`)，表示警告或节奏中断。
  - **结束 (End)**: 统一使用红色系 (`bg-rose-500` 或 `text-rose-600`)，表示运动终结。
  - **开始/继续 (Start/Resume)**: 使用深色系 (`bg-gray-900`)，作为主行动路径。
  - **完成 (Complete)**: 使用绿色系 (`bg-emerald-500`)，表示成功达成目标。

## 4. 静力动作卡片 (Isometric Card) - [Orange Theme]

专为平板支撑 (Plank)、靠墙蹲 (Wall Sit) 等静力训练设计。

### 头部 (Header)
- **运动名称**: 位于左侧，配有蓝色装饰条。
- **类型标签 (Badge)**: 位于右侧。
  - **统一规范**: 所有运动卡片的右上角标签统一采用 **蓝色 (Blue)** 风格。
  - **样式**: `bg-blue-50 text-blue-500`。
  - **文案**: 力量训练显示"力量"，静力动作显示"静力"，有氧运动显示对应的子模式（如"计时器"、"距离"）。

### 数据行 (Set Rows)
采用四列网格布局：`[组号] [计时/目标] [配重] [操作按钮]`
1. **组号**: 两位数序号（如 `01`, `02`），必须从 1 开始显示。移除了顶部的"组"字以保持视觉极简。
2. **计时/目标**: 
   - **大字显示**: 实时秒数 (`text-3xl font-black`)。
   - **辅助信息**: 下方显示"目标: ns"，并配有微型进度条。
3. **配重**: 大字显示重量，下方配有"kg 配重"标签。
4. **操作按钮**: 
   - **设计**: 位于最右侧，采用 `w-16 h-10` 的圆角矩形按钮。
   - **状态**: 
     - **待开始**: 播放图标。
     - **进行中**: 停止图标，背景变为黄色 (Amber-500)。
     - **已完成**: 绿色勾选图标。
5. **激活反馈**: 正在进行的组会应用 `scale-[1.02]` 缩放和浅橙色背景 (`bg-orange-50/30`)，以增强视觉焦点。

## 5. 户外运动卡片 (Outdoor Card) - [Blue Theme]

专为户外骑行、跑步等结合地理位置的训练设计，强调数据与地图的有机融合。

### 头部 (Header)
- **左侧状态条**: 统一使用蓝色 (`bg-blue-500`)。
- **右侧标签**: 显示 "户外" (`bg-gray-50 text-gray-500`)，带定位图标。

### 融合布局 (Merged Layout)
采用数据面板与地图容器垂直融合的设计，最大化利用移动端有限的屏幕空间。

- **数据面板 (Top Half)**:
  - **紧凑布局**: 采用 `relative` 定位，将次要信息（如心率区间）移至右上角绝对定位 (`absolute top-3 right-3`)。
  - **背景色**: 使用浅灰色 (`bg-gray-50/30`) 与下方地图区分。
- **地图区域 (Bottom Half)**:
  - **无遮挡设计**: 移除地图上的覆盖层按钮，保持地图内容（路线、当前位置）清晰可见。
  - **交互**: 点击地图区域直接触发全屏预览，利用 `cursor-pointer` 暗示可交互性。
  - **高度**: 保持紧凑 (`h-48`)，与上方数据面板形成平衡的视觉比例。

### 操作栏 (Action Bar)
- **实体按钮**: 采用带边框 (`border-2`) 和微阴影 (`shadow-sm`) 的实体按钮风格，提供明确的点击反馈。
- **交互态**: 
  - **按下**: `active:scale-90` 显著缩放。
  - **激活**: 对应状态色背景（如暂停时的橙色背景）。

## 6. 文案中文化规范 (Localization)

为了保持界面纯净且符合直觉，遵循以下语言规范：
- **主语言**: 核心交互文案、状态描述、标签名必须使用**中文**。
- **英文保留**: 
  - **单位**: 如 `kg`, `s`, `km`, `bpm` 等。
  - **专有名词**: 如 `ZONE 2`, `PR`, `RPE`, `SET` (仅限作为标识符时) 等已被健身领域广泛接受的专有名词。
- **强制转换示例**:
  - `Weight` -> `配重`
  - `Target` -> `目标`
  - `Duration` -> `时长`
  - `Distance` -> `距离`
  - `Reps` -> `次数`
- **组数显示**: 组数必须从 **1** 开始显示（1-based indexing），禁止在 UI 中显示"第 0 组"。

## 7. 动作设置与 AI 同步规范 (Settings & AI Sync)

在动作设置弹窗 (`ExerciseSettingsModal`) 中，AI 建议的同步逻辑需遵循以下原则：
1. **字段映射**: 
   - 力量训练：同步 `weight`, `reps`。
   - 有氧/静力：同步 `duration`, `distance`，并自动映射到对应的 `targetDuration` / `targetDistance`。
2. **强度同步**: `targetRpe` 需同时更新全局设置与各训练组的 RPE 字段。
3. **即时反馈**: 点击"应用建议"后，下方的训练组列表应立即反映最新的数据变化。

### 数据格式更新 (v2.1)

**重要变更**: 为了统一数据格式，所有运动卡片现在同时维护 `status` (枚举) 和 `completed` (布尔) 两个字段：

```typescript
// 新的 sets 数据结构
{
  status: 'PLANNED' | 'COMPLETED',  // 主要状态字段 (枚举)
  completed: boolean,                // 兼容字段 (布尔) - 自动同步
  // ... 其他字段
}
```

**SummaryCard 现在支持多态显示**:
- 力量训练: `X 次 × Ykg`
- 有氧运动: `M:SS | 目标心率 Zone Z`
- 静力训练: `X 秒 | Y kg 配重`
- 户外运动: `X.XX km | M:SS | 目标心率 Zone Z`

### 运动类型支持

- **力量训练**: 显示重量、次数、RPE 标签
- **辅助训练**: 显示辅助重量、次数、RPE 标签，标签显示 "Assisted"
- **自重训练**: 重量显示为 "-"，显示次数、RPE 标签，标签显示 "Bodyweight"
- **有氧训练**: 显示时长、重量显示为 "-"
- **静力训练**: 显示时长、重量显示为 "-"

### 关键视觉元素

- **头部**: 运动名称 + 右侧箭头图标（低透明度）
- **类型标签**: Assisted 和 Bodyweight 类型显示对应标签
- **组号**: 等宽字体，01、02 格式，灰色
- **完成按钮**: 
  - 已完成：蓝色背景 + 白色勾选图标
  - 未完成：灰色边框 + 白色背景
- **数据列**: 
  - 重量/次数：大字体，小字号单位标签
  - RPE：基于值的颜色标签（绿色 ≤ 7，橙色 > 7 且 ≤ 8，红色 > 8）

## 8. 次级菜单与侧滑交互 (Secondary Menu & Swipe Actions)

为了保持主界面的极简，不常用的操作被收纳在侧滑次级菜单中。

### 交互行为
- **左滑 (Swipe Left)**: 展开右侧操作按钮。
- **右滑 (Swipe Right)**: 展开左侧操作按钮。
- **自动收回**: 点击按钮或点击卡片主体后，菜单自动收回。

### 按钮布局与样式
- **左侧操作 (通常为删除)**:
  - **颜色**: `bg-rose-500` (玫瑰红)
  - **图标**: 垃圾桶图标
  - **文案**: "删除"
- **右侧操作 (通常为工具/设置)**:
  - **布局**: **垂直上下排列**，确保在有限的侧滑宽度内提供更大的点击面积。
  - **按钮 1 (教学)**:
    - **颜色**: `bg-star-accent` (品牌蓝)
    - **文案**: "教学"
  - **按钮 2 (设置)**:
    - **颜色**: `bg-star-dark` (深灰色)
    - **文案**: "设置"

### 视觉细节
- **宽度**: 侧滑展开宽度统一为 `80px`。
- **反馈**: 按钮点击时带有 `active:scale-95` 的触觉反馈效果。
- **分隔线**: 垂直排列的按钮之间使用 `border-t border-white/10` 进行视觉分隔。
