### 1.4 语义检索+逻辑过滤混合查询

**核心价值**: 在单次SQL查询中完成语义理解、逻辑过滤、结构化过滤

```sql
-- 混合查询示例：用户想练胸，但有肩伤
SELECT
  e.id, e.name,
  e.attributes->>'pattern' as pattern,
  e.attributes->'impact_level'->>'shoulder' as impact
FROM exercises e
WHERE
  -- 语义检索：胸部相关动作
  e.embedding <=> query_vector < 0.3
  -- 逻辑过滤：排除高肩压动作
  AND (e.attributes->'impact_level'->>'shoulder')::int < 5
  -- 结构化过滤：只有哑铃
  AND 'dumbbell' = ANY(e.attributes->'equipment_required')
ORDER BY
  e.embedding <=> query_vector
LIMIT 10;
```

### 2.3 意图理解vs计算执行流程

**完整的训练计划生成流程**:

```
用户输入: "我想练胸，但肩膀不太舒服"
    ↓
【AI - 意图理解】
    解析:
    • 核心目标: 胸部训练
    • 限制条件: 肩部不适
    • 隐含需求: 低肩压动作
    ↓
【AI - 自然语言解析】
    提取标签:
    • target: "chest"
    • limitation: "shoulder_discomfort"
    ↓
【Service - 向量检索】
    VectorService.semanticSearch("chest", {
        filter: { shoulder_impact: { $lt: 5 } }
    })
    ↓ 返回: [哑铃卧推, 蝴蝶机夹胸, 绳索夹胸]
    ↓
【Service - 安全过滤】
    RuleService.filterExercises(results, {
        limitations: user.profile_dynamic.active_limitations
    })
    ↓ 过滤: 排除肩部冲击 > 5的动作
    ↓
【Service - 进阶计算】
    ProgressionService.calculateLoad({
        exercise: "dumbbell_bench_press",
        anchor: user.load_anchors.dumbbell_bench_press
    })
    ↓ 计算: 30kg × 0.85 = 25.5kg (精确计算)
    ↓
【AI - 话术生成】
    "针对你的肩部情况，我推荐哑铃卧推。根据你的能力值，
     今天从25.5kg开始，这个重量既能刺激胸部又不会给肩膀
     造成过大压力。"
    ↓
【最终输出】
    完整的训练计划 + 个性化话术
```

│  假设: 每个查询平均10 tokens                                    │
│  • 单次查询: 10 / 1,000,000 × $0.02 = $0.0000002              │
│  • 1000次查询: $0.0002                                         │
│  • 100万次查询: $0.20                                          │
│                                                                  │
│  【增量更新成本】                                                │
│  假设: 每月新增50个动作                                         │
│  • 月度成本: 50 × 50 / 1,000,000 × $0.02 = $0.00005           │
│  • 年度成本: $0.0006                                           │
│                                                                  │
│  【总成本估算】                                                  │
│  第一年 (1000动作, 10万查询):                                   │
│    初始化 + 查询 + 更新 = $0.001 + $0.02 + $0.0006 ≈ $0.02    │

// 实现查询结果缓存
class VectorCacheService {
  private cache = new Map<string, Exercise[]>();

  async semanticSearch(query: string, filters?: FilterOptions): Promise<Exercise[]> {
    const cacheKey = this.generateKey(query, filters);

    // 检查缓存
    if (this.cache.has(cacheKey)) {
      return this.cache.get(cacheKey)!;
    }

    // 执行查询
    const results = await this.vectorSearch(query, filters);

    // 缓存结果 (TTL: 1小时)
    this.cache.set(cacheKey, results);
    setTimeout(() => this.cache.delete(cacheKey), 3600000);

    return results;
  }
}
