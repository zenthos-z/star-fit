# 小工具集合

本目录包含各种实用的小工具。

## 工具列表

### 端口管理器 GUI (`port-manager-gui.html`)

一个可视化的项目端口管理工具，提供图形化界面来监控和管理开发服务端口。

#### 功能特点

- **可视化监控**: 实时显示所有项目端口状态（运行中/空闲）
- **进程信息**: 显示占用端口的进程 PID 和进程名称
- **一键关闭**: 快速终止占用端口的进程
- **命令执行**: 在 GUI 中直接执行系统命令（仅独立模式）
- **启动命令**: 显示各服务的启动命令，支持一键复制
- **自动刷新**: 支持自动刷新端口状态
- **自定义查询**: 支持检测任意端口的状态
- **独立模式**: 无需后端服务即可使用

#### 支持的服务端口

| 服务 | 端口 | 说明 |
|------|------|------|
| 前端 Vite | 43112 | npm run dev |
| 后端 API | 43111 | cd backend && npm run dev |
| LangGraph Studio | 43110 | cd backend && npm run studio |
| 端口管理器 | 43113 | 独立管理服务器 |
| PostgreSQL | 5432 | 数据库服务 (系统保护) |
| Docs 文档站 | 5173 | npm run docs:dev |

#### 端口状态说明

- **● 运行中**: 绿色，端口有进程占用，显示 PID 和进程名
- **○ 空闲**: 灰色，端口未被占用
- **▲ TIME_WAIT**: 黄色，端口处于释放等待状态
- **● 权限不足**: 红色，无法关闭的进程（如 PostgreSQL）

#### 启动方式

##### 方式一：双击启动（最方便）

双击项目根目录的 **`启动端口管理器.bat`** 文件即可启动。

或在 `docs/小工具/` 目录中双击 **`启动端口管理器.bat`** 文件。

##### 方式二：npm 命令

```bash
# 完整命令
npm run port-manager

# 简写别名
npm run pm
```

##### 方式三：直接运行脚本

```bash
node .claude/skills/port-manager/port-manager-server.mjs
```

#### GUI 功能说明

##### 查看端口状态

工具会自动加载并显示所有项目端口的状态卡片。

##### 关闭端口进程

- 对于正在运行的端口，点击"关闭"按钮
- 系统会终止该端口上的所有进程
- PostgreSQL 端口受系统保护，不允许关闭

##### 执行系统命令

在"执行系统命令"区域：
- 输入任意 Windows 命令并点击"执行"
- 使用快捷按钮快速执行常用命令
- 查看命令执行结果

##### 获取启动命令

- 对于空闲的端口，点击"启动命令"按钮
- 在弹出的对话框中查看启动命令
- 点击"复制命令"将命令复制到剪贴板

##### 自动刷新

- 点击右上角的"自动刷新"开关启用/禁用
- 启用后每 3 秒自动刷新端口状态

##### 自定义端口检测

- 在"自定义端口查询"区域输入端口号
- 点击"检测"按钮查看端口状态
- 如果是项目预设端口，会显示详细信息

#### 技术说明

- 纯 HTML 前端实现，通过 API 获取端口状态
- 独立服务器模式使用内置 Node.js HTTP 服务器
- 后端 API 模式: `/api/admin/ports/status`, `/api/admin/ports/kill`
- 使用 Windows 命令行工具（netstat, tasklist, taskkill）
- 仅支持 Windows 开发环境

#### 安全提示

- 端口管理功能仅在开发环境可用
- 请谨慎使用"关闭"功能，避免终止重要进程
- 独立服务器模式仅限本地访问
- 命令执行功能有安全限制，禁止危险操作
