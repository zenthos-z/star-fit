🎯 动作作用

发展上肢水平推力与胸肌厚度，重点刺激胸大肌中束；对肩前束与肱三头也有显著负荷，是上肢推类动作的力量基准项。

💪 发力心法 含呼吸节奏
  • 想象把凳子推开而不是把杠铃举起——注意力在胸，不在手臂；
  • 下放时肩胛持续「夹紧下沉」，像后背夹一支笔，全程不松；
  • 呼吸：下放吸气绷紧核心，过粘滞点后呼气推起，大重量可瓦式呼吸。
📋 步骤
  1. 仰卧调整：平躺凳上，双眼位于杠铃正下方，双脚踩实地面。
  2. 握距与锁定：握距约 1.5 倍肩宽，全握并锁定拇指，肩胛后缩下沉。
  3. 出杠：肩部发力将杠铃推出支架，移至肩关节正上方。
  4. 下放：约 2 秒控制下放至胸中下部，小臂垂直地面，肘部与躯干约呈 45–75°。
  5. 推起回杠：胸部发力沿微弧线推起，手臂接近伸直；完成组数后回杠入架，确认卡扣锁定。
⚠️ 注意事项
  • 大重量务必使用安全销或有人保护，失败时让杠铃压至胸口缓推滚离；
  • 手腕保持中立，杠压在掌根而非手指，必要时使用护腕；
  • 起桥幅度以臀部不离开凳面为限，腰椎不适立即停组。
❌ 常见错误
  • 半程弹震借力：下放触胸即弹起，失去离心控制；
  • 肘部外展至 90°：肩关节压力显著增大；
  • 空握或拇指未锁定：大重量下杠铃易滚动脱手。
