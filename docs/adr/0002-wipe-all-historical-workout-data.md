# 清空全部历史训练与心率数据

现有数据库中约百名用户的历史数据全部来自测试期（手动录入心率链路被判定为错误链路，
其产物即污染数据），对将来走势图、脚本分析与 AI 解读全是干扰项。决定：随本次心率重构
一并**全量清空**运动数据（sessions、rpe_logs、deviation_logs 及将来的
heart_rate_samples），不迁移、不打标、不保留。用户账号与档案表保留。

## Consequences

- 分析与趋势功能上线时从零开始积累——这是接受的代价，换来干净的分析集。
- 未来读者看到库为空/数据从某日期起才存在，原因即本 ADR。
- 清空操作须走脚本并先备份（一次性 dump 归档后执行），不做不可逆裸删。
