## 使用建议

1. **避免配色过多**: 同一页面不超过 3 种强调色
2. **对比度要求**: 符合 WCAG 可访问性标准
3. **优先使用 Tailwind 类名**: 保持配置统一性
4. **禁止硬编码颜色值**: 使用设计令牌

---

## 代码示例

```tsx
// ✅ 正确：使用 Tailwind 类
<button className="bg-blue-500 text-white px-4 py-2 rounded-lg">
  主要按钮
</button>

// ❌ 错误：硬编码颜色
<button style={{ backgroundColor: '#3B82F6' }}>
  主要按钮
</button>

// ✅ 正确：使用设计令牌
import { primitives } from '@/v2/lib/design-tokens';
const color = primitives.color.primary[500];
```
